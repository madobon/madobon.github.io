*   **Loop 2 (Middle):** Contains the $1\Omega$ resistor, a $5\Omega$ resistor, and a $4\Omega$ resistor shared with Loop 3.

**2. Formulate Mesh Equations**

*   **For Loop 3:**
    There is a current source of 2A in the outer branch. Since the mesh current $I_3$ is defined as clockwise and the current source points upward (counter-clockwise relative to the loop), we can directly determine:
    $$I_3 = -2\text{ A}$$

*   **For Loop 1 (KVL):**
    Sum of voltage drops equals zero:
    $$-10 + 2I_1 + 1(I_1 - I_2) = 0$$
    $$3I_1 - I_2 = 10 \quad \text{--- (Equation 1)}$$

*   **For Loop 2 (KVL):**

    $$1(I_2 - I_1) + 5I_2 + 4(I_2 - I_3) = 0$$
    $$-I_1 + 10I_2 - 4I_3 = 0$$

    Substitute $I_3 = -2\text{ A}$ into this equation:
    $$-I_1 + 10I_2 - 4(-2) = 0$$
    $$-I_1 + 10I_2 + 8 = 0$$
    $$-I_1 + 10I_2 = -8 \quad \text{--- (Equation 2)}$$

**3. Solve the System of Equations**

From Equation 1, we can express $I_2$ in terms of $I_1$:
$$I_2 = 3I_1 - 10$$

$$-I_1 + 10(3I_1 - 10) = -8$$
$$-I_1 + 30I_1 - 100 = -8$$

$$I_1 = \frac{92}{29} \approx 3.17\text{ A}$$
